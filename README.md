# DOL-AveryOrphanageNote
是否厌倦了每次踏入孤儿院大厅，就被艾弗里强行拽去办公室、开始强制收养的一次性事件？
本 Mod 让你掌握主动权。 在贝利的办公室（贝利不在时），你可以选择给贝利留一张便签： 
「给贝利留便签，告诉他你不想跟艾弗里走」—— 开启拦截，此后进入孤儿院大厅时，艾弗里的强制收养事件将不再触发； 
「给贝利留便签，告诉他你对艾弗里没那么排斥了」—— 取消拦截，恢复原版事件。  
设计细节： 选项仅在贝利不在办公室（早 7 点至 9 点之外）时出现，避免与本体剧情冲突； 仅当原版收养事件具备触发条件时（艾弗里线已激活、尚未进入庄园）才生效，不影响其他任何事件； 
开局默认关闭，需你主动留便签才会开启。
